🔑 GitHub Token 生成教程（更新用）

  1. 浏览器登录 GitHub，打开 github.com/settings/tokens?type=beta（注意链接带 ?type=beta，进 Fine-grained 版）
  2. 点右上角绿色按钮 Generate new token
  3. Token name 随便起（如 push）；Expiration 建议选 90 days 或更长
  4. Repository access 选 Only select repositories → 下拉勾选 Yukio1014/HOME
  5. Permissions → Repository permissions → 找到 Contents，勾选后把级别改为 Read and write（其他权限不动）
  6. 点最下方绿色 Generate token
  7. 立刻复制以 github_pat_ 开头的长字符串（只显示一次，关页面就看不到了）
⚠️ 找不到 Contents 的 Read and write？先在权限弹窗里勾选 Contents，级别下拉才会出现。Token 失效（Bad credentials）就是过期了，重新生成一个即可。
